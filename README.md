# Mi Proyecto 🚀
This folder contains two computation files performed in GAP on the search for skeletal chiral polyhedra and 4-polytopes whose edge graphs are contained in the 1-skeleta of the six regular convex 4-polytopes.

## Archivos incluidos:
* **Archivo PDF:** (This file contains the code developed in GAP along with the obtained results with brief explanations.)
* **Archivo de texto:** (This file contains the raw GAP code so that the user can copy and paste it into the terminal.)
